🚀 Built my first “Chat With Your Documents” RAG application!

This project helped me explore how Retrieval-Augmented Generation (RAG) connects an LLM with information from custom documents.

🔍 What I implemented:
• Document text extraction (PDF, DOCX, TXT, Markdown)
• Text chunking with overlap
• Semantic embeddings using Sentence Transformers
• Vector storage and similarity search with ChromaDB
• Context-grounded answers using an OpenAI chat model
• Retrieved-context inspection to make answers easier to verify

🧠 Key takeaway: a useful RAG system is not just an LLM prompt. Document preparation, chunking, embedding quality, retrieval, and grounding all influence the final answer.

🛠️ Tech stack: Python | Streamlit | Sentence Transformers | ChromaDB | OpenAI API
